# 玩法对照表（NSMB → 本实现）

本文档逐条对照《新超级马里奥兄弟》的玩法要素与本项目实现状态，
方便后续 agent 评估还差什么。

## 移动与招式

| NSMB 要素 | 状态 | 实现位置 |
|---|---|---|
| 走/跑双极速 + 急刹 | ✅ | player._horizon, tuning.walk_max/run_max/skid_decel |
| 变高跳（按住更高） | ✅ | gravity_rise / gravity_release |
| 跳跃预输入 + 土狼时间 | ✅ | input.buffered + TUNE.coyote |
| 墙滑 + 墙跳 | ✅ | player._wall_slide_check（贴墙按方向才滑，跳即反推 2.05px/f） |
| 旋转跳（弹开刺敌不受伤） | ✅ | player.spinning + level._collisions 的 spin_landing 分支 |
| 下砸（震波杀敌/碎砖/按音符块） | ✅ | player._vertical 下+jump → level.pound_impact |
| 游泳（划水/慢沉/出水） | ✅ | player._vertical 的 in_water 分支 |
| 蹲/滑铲 | ✅（滑铲只有姿势没有攻击判定） | player._anim "crawl" |

## 方块

| 方块 | 字符 | 行为 |
|---|---|---|
| ? 块 | `?` | 顶出金币，变 X |
| 道具块 | `!` | 顶出火花（按形态可改出蘑菇，目前固定火花） |
| 砖块（币） | `B` | 顶出金币变 X |
| 碎砖 | `b` | 大/火/巨大形态或下砸撞碎（四向飞屑） |
| 多币块 | `C` | 4 秒窗口连顶最多 10 币 |
| 音符块 | `N` | 落上去大弹跳（下砸踩中弹得更高），顶了只响 |
| 隐藏块 | `H` | 上升中顶到才显形出金币 |
| 单程平台 | `=` | 只挡下落 |
| 尖刺 | `S` | 踩上受伤 |
| 用过的块 | `X` | 死块 |

## 手感基准（tuning.py，60Hz）

- 满跳 ≈ 4.5 格（72px）；轻点 ≈ 2 格；下落重力 ×1.25
- 走 1.32 / 跑 2.06 px/f；弹簧 5.8 格；音符块 5.25 格（下砸 5.5）
- 踩踏连击：100,200,400,500,800,1000,2000,4000,8000→1UP
